# 1 拍の指示書 v1（/loop で定期的に再注入する）

用途: `/loop 20m prompts/beat_v1.md を読み、その 1 拍を実行せよ`。目標は prompts/goal_v<N>.md、規則は CLAUDE.md（skill: autonomous-run）。
1 拍 = 下の 5 手を上から順に、このターンの中でやり切る。前の拍の作業が途中なら、それを続けてから 5 手に入る。

1. **状態を取る（短く）**: 計算資源の稼働、終わった run、queue の回答、docs/backlog.md の先頭 3 件。
2. **空きを埋める**: 資源が空いていれば、予想を設定の `prediction` に書いた計算だけを入れる。
3. **考える（拍の中心）**: 予想と違った結果を 1 つ選び、なぜ外れたかと次の仮説を書く。予想どおりの結果しか無いなら、より大胆な問いを backlog の先頭に積む。
4. **進める**: backlog の先頭を 1 つ前進させる。独立な作業はサブエージェントに並行で投げる。
5. **記録する**: devlog に 3 行（予想・結果・判断）、docs/state.md を更新し、commit する。

4 拍に 1 回: candor-check agent でぶっちゃけ点検。答えを state.md に貼り、受け入れるか根拠つきで退ける。

禁止: 計算の完了を待つだけで拍を終える / 予想を書かずに run を投げる / 報告だけ書いて何も前進させずに終える。
