# prompts/

LLM に渡すプロンプトを置く。

- 1 プロンプト 1 ファイル: `<用途>_v<N>.md`（例: `summarize-paper_v2.md`）
- 改訂したら上書きせず `v<N+1>` を作る。過去の run が使った版を残すため（検査なし）
- 下の「一覧」に、各版の用途と、どれが現行かを書く（/goal などで指すのは現行の版）
- 長期の司令（/goal）は本文をここに置き、/goal にはこのファイルを指す短い文だけを渡す（会話が要約されても読み直せる）

## 一覧
- beat_v1.md: /loop で再注入する 1 拍の指示書の雛形（`/loop 20m prompts/beat_v1.md を読み、その 1 拍を実行せよ`）
