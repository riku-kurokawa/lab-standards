# 長い自律運用

nla-solver・accelerated-diff-pat での数日間の運用で、効いたものと逆効果だったものから作った手順。

## 失敗の型（これを防ぐための手順）
- **待つ**: 計算を投げて完了を待ち、ターンを終える。通知が来るまで何もしない。
- **薄れる**: 長い会話が要約され、最初に渡した目標や規則が消える。
- **計算で確かめに行く**: 計算する前に分かる結論を、時間と資源を使って確かめる。
- **活動量に最適化する**: commit 数・行数・サーベイ本数のノルマを与えると、手は増えるが考えは増えない。
- **安全な回り道**: 主線を問い直さず、確かめやすい小さな一歩を積み続ける。当然の結論を避ける。

## 置き方（3 つのファイル + 2 つのコマンド）
| 何 | どこ | 役割 |
|---|---|---|
| 目標 | `prompts/goal_v<N>.md` | 究極の目標、前提（計算せずに分かる結論）、論文の合格基準、報告の形式。改訂は版を上げる |
| 1 拍の指示書 | `prompts/beat_v<N>.md` | 1 拍でやる 5 手（雛形あり）。短く保つ |
| 状態 | `docs/state.md` | 前提の表、ぶっちゃけ点検の表、予想の当たり外れ、次の一手。毎拍、該当欄を上書き |
| 未着手 | `docs/backlog.md` | `- [ ] ...`。目標に最も効く順。前提に反する項目は理由を書いて消す |

```
/goal prompts/goal_v<N>.md の目標を達成する。毎拍の最初にこのファイルと docs/state.md・docs/backlog.md を読み直す。
/loop 20m prompts/beat_v<N>.md を読み、その 1 拍を実行せよ
```
- /goal の本文はファイルを指す短い文にする（本文を貼ると要約で消える）。/loop は毎回原文を渡し直す。
- 間隔は、1 拍に新しい結果が 1 つ以上届く長さ（計算 1 本の所要時間の 1.5 倍程度）。短すぎると状態を取るだけで拍が終わる。
- 規則（予想の関門など）は CLAUDE.md に置く。ループを止めるのは人間だけ（`claude.allow_self_stop = false` の既定では hooks が CronDelete・ScheduleWakeup の stop を拒否する）。CLAUDE.md は要約の後も読まれる。

## 1 拍の 5 手
1. 状態を取る（短く）: 資源の稼働、終わった run、queue の回答、backlog の先頭。
2. 空きを埋める: 予想を書いた計算だけを入れる。
3. 考える（拍の中心）: 予想と違った結果を 1 つ選び、なぜ外れたかと次の仮説を書く。予想どおりの結果しか無いなら、問いが易しすぎる。
4. 進める: backlog の先頭を 1 つ前進。独立な作業（サーベイ・導出・執筆・監査）はサブエージェントに並行で投げる。
5. 記録する: devlog に 3 行（予想・結果・判断）、state.md を更新、commit。

## 予想の関門
- run の前に、桁の見積もり・既知の理論・既存の結果から、結果を数値で予想して設定の `prediction` に書く（meta.json に残る。
  `lab.toml` の `runs.require_prediction = true` で強制できる）。
- 予想に自信があり、主張の証拠として必須でない計算は回さない。「導出で確定」として devlog に書く。
- 事前登録の修正は、結果を見る前に「amendment N（pre-computation）」として commit する。結果を見た後に基準を動かさない。

## ぶっちゃけ点検（4 拍に 1 回）
`candor-check` agent を Agent ツールで起動し、目標・前提・主張・最新の結果の要約だけを渡す（作業の記録を渡さない）。
答え（避けている当然の結論 / 捨てるべき線 / 最も大胆で当たれば最大の価値がある一手）を state.md の表に貼り、
1 つずつ「受け入れ」か「根拠つきで退ける」を書く。受け入れた「捨てる線」は backlog から理由つきで消す。

## 撤回と捨てる線
- 自分の主張の誤りを見つけたら、要旨・表・結論を直し、旧値を消さずに「撤回: 理由」と併記する。撤回は成果である。
- 価値は「主張を支える結果」「撤回した主張」「捨てた線」で測る。commit 数・行数・本数のノルマは置かない。

## 範囲を縮める判断
目標の範囲を縮める・主線を変える判断は `labkit queue ask` に積み、仮の判断では範囲を保つ。決めるのは人間。
